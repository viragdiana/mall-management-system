# Mall Management System

A full-stack Java application built with Spring Boot for managing malls, shops, customers, purchases, and staff. Developed following MVC architecture and SOLID principles.

## Tech Stack

- **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
- **Frontend:** Thymeleaf, HTML/CSS
- **Build Tool:** Maven

## Architecture

- **Model:** Entities (Mall, Shop, Customer, Staff, Purchase)
- **Repository:** Spring Data JPA repositories for relational data persistence
- **Service:** Business logic layer
- **Controller:** Spring MVC controllers with Thymeleaf view integration

## How to Run

1. Open the project in IntelliJ
2. Run `MallManagementApplication`
3. Open http://localhost:8080 in your browser
